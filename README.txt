STUDYMATE — UI XML + Jetpack Compose

Isi tugas:
1. Login: app/src/main/res/layout/activity_main.xml
2. Register: app/src/main/res/layout/activity_register.xml
3. Forgot Password: app/src/main/res/layout/activity_forgot_password.xml
4. Homepage Jetpack Compose: app/src/main/java/com/example/studymate/HomeActivity.kt

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka Android Studio > Open > pilih folder StudyMate_XML_Compose.
3. Tunggu Gradle Sync selesai.
4. Jalankan menggunakan emulator atau HP Android.

Catatan:
- Login/register/reset password ini demo UI, belum terhubung ke database atau email sungguhan.
- Login demo akan membuka Homepage selama email dan password tidak kosong.
- Jika Android Studio meminta SDK, pasang Android SDK Platform 35 atau sesuaikan compileSdk/targetSdk di app/build.gradle.kts.
- Tema aplikasi: StudyMate, aplikasi sederhana untuk membantu mahasiswa melihat daftar tugas.
